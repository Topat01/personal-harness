# independent-check (6단계 검증)

1. 사람에게 비교할 핵심 결과 1~3개를 확인한다(예: 결과 건수, 상위 항목, 합계).
2. 구현 모듈을 import하지 않는 1회용 스크립트(또는 셸 명령)로 원본에서 직접 다시 계산한다. 같은 로직을 복사하지 말고 다른 방식(다른 집계 순서, 다른 도구)으로 한다.
3. 구현 결과와 비교한다.
```
비교 항목 | 구현 결과 | 재계산 결과 | 일치
다른 항목(최대 10개): 원본 행·값
원인 추정:
```
4. 1회용 스크립트는 제출물에 넣지 않는다(필요하면 사람이 정함). 결과는 DECISIONS·제출 설명의 "검증 결과"에 쓸 수 있게 한 줄로 요약한다.
