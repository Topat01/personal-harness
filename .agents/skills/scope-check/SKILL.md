# scope-check

## 절차
1. 요구 목록: 과제 안내의 필수조건·제출물 + `PLAN.md`의 확인한 조건(C1…) + "안 만들 것".
2. 변경 목록: `git diff --stat <시작 커밋>`, `git status --short`(미추적 파일 포함).
3. 대조표를 만든다.
   - 요구마다: 충족한 파일·함수 / 확인한 테스트 / 없음
   - 변경마다: 어느 요구를 위한 것인지 / **해당 없음**(과설계 후보)
4. 보안 3줄: 비밀값처럼 보이는 문자열, 외부 입력(파일 경로·파싱) 예외 처리, 개인·사내 정보 노출.
5. 정리 후보: 제출에 필요 없는 산출물·캐시·가상환경·임시 파일.

## 출력
```
| 요구 | 충족 위치 | 확인 | 상태 |
| 변경 | 위한 요구 | 판단(유지/제거 후보) |
보안: …
정리 후보: …
```

## 금지
- 직접 삭제·수정. 사람이 고를 수 있게 목록만 낸다.
