# subagent-brief

## 지시서 형식 (이대로 서브에이전트에게 넘긴다)
```
목표:
범위: 이 파일·함수만 (목록)
읽을 것: AGENTS.md, PLAN.md의 C(번호)
금지: 원본 데이터 수정 / 새 의존성 / 범위 밖 파일 변경 / 요구에 없는 기능
완료 조건: (테스트 이름) 통과 + (실행 명령) 출력
보고: 변경 파일, 실행 명령과 출력 원문, 가정
```

## 절차
1. 사람이 맡길 작업을 정하면 위 지시서를 채워 보여 주고, 확인을 받은 뒤 위임한다.
2. 결과가 돌아오면 완료 조건의 명령을 **직접 다시 실행**해 확인하고, 범위 밖 변경이 있는지 `git diff --stat`으로 본다.
3. 사람에게 "확인한 것 / 범위 밖 변경 / 남은 문제"를 3줄로 보고한다.
