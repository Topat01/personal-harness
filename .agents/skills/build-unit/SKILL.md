# build-unit (5단계 짓기)

## 시작 전 확인 (빠지면 묻고 멈춘다)
- 목표: 함수·화면·명령 하나
- 근거: PLAN.md의 조건 ID(C…)
- 틀리기 쉬운 곳: 경계·빈 값·형식
- 완료 조건: 통과해야 할 테스트 또는 실행 결과

## 절차
1. 테스트를 먼저 쓴다. 기대값은 구현과 다른 방법(원본에서 직접, 손 계산)으로 정한다. 경계마다 하나.
2. 테스트가 실패하는 것을 확인한다.
3. 최소한으로 구현한다. 원본 데이터 수정·새 의존성·관계없는 파일 변경 금지.
4. 테스트를 실행한다. 통과할 때까지 같은 오류로 2회 넘게 재시도하지 않는다(넘으면 사람에게 보고).
5. 보고:
```
변경 파일:
테스트 출력(원문 마지막 몇 줄):
가정:
커밋 메시지 제안: feat: (무엇) (C번호, 테스트 n passed)
```
6. 커밋은 사람이 결과를 확인한 뒤 한다. 이어서 `unit-explain`을 권한다.
