# scaffold (뼈대)

목적: 기능이 없어도 **띄우고, 들어가고, 제출할 수 있는 껍데기**를 먼저 만든다. 핵심 계산·판단 로직은 `engine`에서 한다.

1. `SPEC.md` 1~3절에서 실행 환경 요구와 인프라성 요구만 고른다. 지시문이 요구하지 않은 것은 만들지 않는다. 고른 목록을 사람에게 한 줄로 보여 주고 시작한다.
2. 스택: 지시문이 정했으면 그대로, 아니면 이미 설치된 런타임으로 가장 단순한 것(새 의존성은 먼저 묻는다).
3. 만든다(요구된 것만):
   - 서버: `0.0.0.0` 바인딩, 포트는 환경변수
   - 설정·비밀값: 환경변수 + `.env.example`(값은 예시)
   - 저장소: 빈 상태에서 시작하면 스키마와 초기 데이터를 자동 준비, 재시작해도 남게
   - 헬스체크 주소
   - 로그인과 역할: 역할별로 들어갈 수 있게, 권한은 서버에서 확인
   - 화면: 요구된 화면마다 빈 자리(제목과 "준비 중")
   - 컨테이너 파일(요구된 경우)
4. 테스트는 쓰지 않는다. 대신 실제로 확인한다: 서버 실행 → 헬스체크 응답 → 역할별 로그인 1회 → (가능하면) 컨테이너 빌드. 명령과 결과를 그대로 보고하고, 못 한 것은 `NOT_RUN`.
5. `SPEC.md` 해당 행 상태를 갱신하고, AGENTS.md 4절 형식으로 설명(채팅 5줄, NOTES 4절 3줄 + 빈 `내 말:`), 커밋한다.

멈출 때: 같은 설치·빌드 오류 2회, 또는 뼈대 작업이 길어지면 사람에게 묻는다(뼈대는 완성도보다 빨리 끝내는 것이 중요하다).
