# review-only (6단계 검증)

파일을 고치지 않는다. 목록만 낸다.

1. `git diff --stat <시작 커밋>`과 바뀐 함수만 읽는다.
2. 아래 항목별로 찾는다. 항목마다 파일:줄과 이유 한 줄.
```
요구 미충족(README·PLAN의 C 기준):
빠진 경계(정확히 기준값/넘는 값/빈 값/깨진 형식/0건):
하드코딩·샘플(예시 ID·값)에만 맞춘 곳:
문서(PLAN·DECISIONS·README)와 코드가 다른 곳:
실행 근거 없이 "된다"고 적힌 곳:
```
3. 사람이 고칠 것을 고르면 `build-unit`으로 처리한다.
