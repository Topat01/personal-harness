# kickoff (1단계 읽기)

코드·파일을 만들거나 고치지 않는다. 읽고 실행해서 보고만 한다.

## 절차
1. AGENTS.md에서 지킬 규칙 5줄을 요약한다.
2. 작업 폴더 파악: `python3 <kit>/tools/scan.py`를 실행한다(`<kit>`은 AGENTS.md에 적힌 하네스 경로).
   - **스크립트가 없거나 실패하면** 같은 내용을 셸로 한다: `ls -la`, `find . -maxdepth 2 -not -path '*/.*' -type f | head -50`, README·과제 안내 전체 읽기, `package.json`·`requirements.txt`·테스트 폴더 확인, `git log --oneline -5`.
   - 홈 폴더의 환경 파일(.bashrc, .profile, .config 등)과 하네스 폴더는 과제 파일이 아니니 무시한다.
3. 데이터 파일이 있으면 `python3 <kit>/tools/eda.py <파일…>`의 "질문 거리"만 가져온다.
   - **실패하면** `head -5`, `wc -l`, 컬럼별 빈 값·고유값 개수를 1회용 명령으로 확인한다(파일 전체를 읽지 않는다).
4. 아래 표로 보고한다.

## 출력
```
지킬 규칙 5줄:
| 항목 | 내용 |
| 과제 유형 | A 데이터→결과물 / B 기존 코드 수정 / C 서비스·도구 / D 문서 응답 / E 분석 보고 (근거) |
| 제출물 | README가 요구한 것 전부(파일명 그대로) |
| 실행 환경 | 언어·런타임·있는 패키지·포트 |
| 해석이 갈리는 지점 | 1. 2. 3. (각각 답에 따라 결과가 어떻게 달라지는지) |
| 질문 거리 | 데이터·코드에서 본 사실 기반 후보 |
| 가장 작은 끝까지 도는 버전 | 한 줄 |
```
